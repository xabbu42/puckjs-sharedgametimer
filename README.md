# [Puck.js](https://www.puck-js.com) remote for [sharedgametimer.com](https://sharedgametimer.com)

Transform your [Puck.js Bluetooth Beacon](https://www.puck-js.com) into a wireless remote control for [sharedgametimer.com](https://sharedgametimer.com).

Video: https://xabbu42.github.io/puckjs-sharedgametimer/video.mp4

## Features

- **Button Controls:** Single press, long press, and double press detection
- **Motion Detection:** Shake gesture and orientation changes
- **Multi-Player Support:** Configure specific seat assignments
- **Led Feedback:** Show active player and active buttons

## Installation

**Option 1:** Download the [script](app.js) and install it manually using the [Espruino Web IDE](https://www.espruino.com/ide/) or the [espruino command line tool](https://www.npmjs.com/package/espruino).

**Option 2:** Install directly from the web interface: https://xabbu42.github.io/puckjs-sharedgametimer/

## How to Use

1. Install the script to your Puck.js using one of the methods above
2. Visit [sharedgametimer.com](https://sharedgametimer.com) and start or join a game session
3. Connect your Puck.js via [Bluetooth LE](https://sharedgametimer.com/remote-control/bluetooth)
4. Use button presses and gestures to control the game timer

**Note:** Make sure your browser supports Web Bluetooth and that Bluetooth is enabled on your device.
