# [Puck.js](https://www.puck-js.com) remote for [sharedgametimer.com](https://sharedgametimer.com)

A script to use the [Puck.js Bluetooth Beacon](https://www.puck-js.com) as a remote for [sharedgametimer.com](https://sharedgametimer.com).

You can download the [script](app.js) and install it using the [Espruino Web IDE](https://www.espruino.com/ide/) or the [espruino command line tool](https://www.npmjs.com/package/espruino).

Or you can install it directly from here: https://xabbu42.github.io/puckjs-sharedgametimer/

After that you can connect your [Puck.js](https://www.puck-js.com) to the [sharedgametimer.com](https://sharedgametimer.com) using [Bluetooth LE](https://sharedgametimer.com/remote-control/bluetooth).
