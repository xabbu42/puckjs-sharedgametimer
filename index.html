Transform your Puck.js Bluetooth Beacon into a wireless remote control for sharedgametimer.com.

Features

  • Button Controls: Single press, long press, and double press
  • Motion Detection: Shake gesture and orientation changes
  • Multi-Player Support: Configure specific seat assignments
  • Led Feedback: Show active player and active buttons

How to Use

  1. Install the script to your Puck.js using one of the methods above
  2. Visit sharedgametimer.com and start or join a game session
  3. Connect your Puck.js via Bluetooth LE
  4. Use button presses and gestures to control the game timer

Note: Make sure your browser supports Web Bluetooth and that Bluetooth is enabled on your device.
